# Supplementary Table S1

`table_s1_environment_level_diagnostics.csv` is the machine-readable source
for Supplementary Table S1 in the manuscript. It combines only
environment-level fields from the canonical files:

- `results/b2a_external_synthetic_environment_summary_v1.csv`
- `results/draft2_reviewer_zero_composition_by_environment_v1.csv`

The columns report query count, exact-zero/nonzero composition, zero
proportion, mean absolute ground-truth effect, and the B2A MAE, RMSE, Pearson,
and Spearman diagnostics for each of EXT0--EXT5. No values are estimated or
invented during formatting. A separately formatted PDF version may be supplied
through the journal submission system; this CSV remains the auditable source.
