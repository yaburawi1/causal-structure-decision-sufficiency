# Data provenance

## Primary benchmark

The primary decision-sufficiency analysis uses the publicly released **NeurIPS 2022 Causal Insights for Learning Paths in Education** benchmark.

This repository does not automatically redistribute third-party benchmark files. Reproduction instructions should obtain the benchmark from its official public source and preserve the original licensing and attribution requirements.

## External synthetic validation

The external validation environments are author-generated synthetic dynamic causal systems created for this study. Publication-facing generation configuration, seeds, and canonical outputs should be stored in this repository so that the reported external validation can be audited and reproduced.

## Exclusions

The repository must not contain:

- private institutional student records;
- personally identifiable information;
- unrelated LENS-C project data;
- undocumented development scratch data;
- data whose redistribution is not permitted by the original license.
